# Nilesh Naresh Padmawar – Online Resume

A multi-page personal resume website built with pure HTML & CSS.

## Pages
- **index.html** – Main resume (Summary, Work Experience, Skills, Education, Awards)
- **hobbies.html** – Hobbies & Interests
- **contact.html** – Contact Details

## How to Run Locally
Just open `index.html` in any web browser — no build tools or server needed.

## How to Deploy on GitHub Pages
1. Push this folder to a GitHub repository (e.g. `my-resume`)
2. Go to **Settings → Pages**
3. Set **Source** → `main` branch → `/ (root)`
4. Your site will be live at: `https://<your-username>.github.io/my-resume/`
